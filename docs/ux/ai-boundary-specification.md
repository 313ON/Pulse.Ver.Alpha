# مرز AI در PULSE

AI در آینده می‌تواند مفهوم‌ها را توضیح دهد، کاربر را راهنمایی کند، متن طبیعی را به intent پیشنهادی تبدیل کند، draft هدف/هدف جزئی بسازد، گزارش را خلاصه کند، ناهماهنگی احتمالی را نشان دهد و جستجو را بهتر کند.

AI مرجع حقیقت نیست و حق نوشتن مستقیم به persistence، تغییر permission، تأیید import، جعل provenance، پرکردن داده تاریخی یا دورزدن domain rule ندارد.

الگوی الزامی:

`User intent → AI proposal/translation → user review → application service → domain rules → validation → persistence`

هر پیشنهاد باید قابل مشاهده، قابل ویرایش، با منبع و سطح اطمینان مناسب باشد. اگر منبع/معنا نامعلوم است، AI باید `UNKNOWN` یا `REVIEW_REQUIRED` نشان دهد، نه حدس.
