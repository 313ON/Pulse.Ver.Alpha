# سیاست دسترس‌پذیری و سواد دیجیتال

- RTL و فارسی از ابتدا؛ ترتیب فوکوس و خواندن با زبان سازگار.
- متن پایه خوانا، حداقل اندازه قابل تنظیم، line-height مناسب و contrast قوی.
- هر آیکون همراه متن یا accessible name؛ وضعیت فقط با رنگ منتقل نشود.
- keyboard navigation کامل، focus واضح، landmark و label/description برای screen reader.
- کنترل‌های لمسی با hit-area مناسب؛ layout responsive برای desktop، tablet و mobile.
- empty/loading/error state توضیح می‌دهد چه می‌بینیم، چرا خالی است و قدم بعدی چیست.
- safe default، undo یا draft/recovery در عملیات قابل بازگشت؛ confirmation فقط برای پیامد واقعی.
- validation نزدیک فیلد، فارسی و عملیاتی؛ خطا با مثال و امکان اصلاح.
- tooltip فقط برای توضیح تکمیلی، نه اطلاعات حیاتی؛ onboarding hint قابل ردکردن و قابل بازگشت.
- زمان، تاریخ جلالی و اعداد در قالب قابل فهم؛ داده خام و شناسه در advanced.

معیار پذیرش هر قابلیت جدید: بدون mouse قابل انجام باشد، با zoom و viewport باریک قابل استفاده بماند، و کاربر کم‌تجربه بتواند از empty/error state مسیر بعدی را بفهمد.
