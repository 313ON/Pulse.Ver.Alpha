# مشخصات معماری اطلاعات PULSE

## ناوبری هدف

ناوبری پیش‌فرض بر اساس نیت کاربر است: **کارهای من، برنامه من، اهداف، گزارش عملکرد، پیگیری، گزارش‌ها**. مدیریت سامانه و نمای تخصصی داده‌ها فقط با permission و در سطح پیشرفته نمایش داده می‌شوند. مسیرهای فعلی مانند اهداف جزئی، فعالیت‌ها، KPI، ریسک و وابستگی به‌عنوان نمای تخصصی/زمینه‌ای حفظ می‌شوند، نه الزاماً آیتم اصلی برای همه.

### ناوبری اصلی

| بخش | کاربرد | سطح | وضعیت فعلی/مسیر پایه |
|---|---|---|---|
| کارهای من | اقدام‌های واگذارشده، مهلت و پیشرفت | ساده | `/actions` |
| برنامه من | مسیر برنامه و context چرخه/واحد | ساده | `/program` |
| اهداف | هدف‌های سازمان و واحد | حرفه‌ای | `/goals` |
| گزارش عملکرد | پیشرفت، KPI و سلامت برنامه | حرفه‌ای | `/reports` و داشبورد |
| پیگیری | بازبینی، ریسک و وابستگی | حرفه‌ای | `/monthly-reviews`, `/risks`, `/dependencies` |
| گزارش‌ها | مشاهده و export گزارش | حرفه‌ای | `/reports` |
| مدیریت سامانه | کاربران، سازمان، import و تنظیمات | مدیر | `/users`, `/departments`, `/roles`, `/imports`, `/settings` |

## اقدامات

اقدام سراسری: جستجو، مشاهده اعلان‌ها، تغییر چرخه/واحد در صورت مجاز بودن، پروفایل و کمک. اقدام زمینه‌ای: ایجاد زیرمورد، ثبت پیشرفت، ثبت بازبینی، افزودن ریسک/وابستگی و export در همان context. شناسه و provenance در پنل پیشرفته جزئیات دیده می‌شود.

## جستجو

جستجوی واحد باید به‌تدریج هدف، هدف جزئی، فعالیت، اقدام، KPI، شخص، واحد و گزارش را پوشش دهد و نتیجه را با نوع، عنوان، واحد، چرخه و وضعیت نشان دهد. جستجوی فعلی `CommandHeader` و `/api/search` نقطه شروع است؛ قرارداد آینده باید query انسانی، مترادف‌ها، فیلترهای صریح و permission-aware result را پشتیبانی کند.

## صفحه و context

هر صفحه باید breadcrumb انسانی، context چرخه/واحد، وضعیت بارگذاری، empty state و action بعدی داشته باشد. context در انتقال بین داشبورد، برنامه و گزارش حفظ شود. نمای تخصصی می‌تواند tree و روابط دامنه را نشان دهد، اما پیش‌فرض باید خلاصه قابل فهم باشد.

## سطح دسترسی نمایش

عدم دسترسی نباید به‌صورت منوی شکسته یا خطای فنی دیده شود. آیتم administrator-only مخفی یا با توضیح «نیازمند دسترسی مدیر سامانه» ارائه شود؛ این تصمیم هرگز جایگزین authorization سمت سرور نیست.
