# سیاست زبان و اصطلاحات

زبان پیش‌فرض PULSE فارسی روشن، RTL و محترمانه است. اصطلاح فنی فقط وقتی دیده می‌شود که برای ممیز/مدیر سامانه ارزش عملی داشته باشد؛ در آن حالت کنار ترجمه انسانی و در سطح پیشرفته می‌آید.

| اصطلاح داخلی | زبان کاربر | توضیح کوتاه | نمایش فنی |
|---|---|---|---|
| Program | برنامه | مجموعه مسیر و هدف‌های یک چرخه | فقط در diagnostics |
| Goal | هدف | نتیجه‌ای که سازمان/واحد می‌خواهد به آن برسد | «هدف راهبردی» در نمای تخصصی |
| Objective/Sub-goal | هدف جزئی | گام نتیجه‌ای برای رسیدن به هدف | parent ID پنهان |
| Activity | فعالیت | کاری که چند اقدام را سازمان می‌دهد | نمای تخصصی |
| Action/Work item | اقدام / کار | کاری با مسئول و مهلت مشخص | public ID فقط پیشرفته |
| KPI | شاخص عملکرد | روشی برای سنجش نتیجه | «شاخص» در سطح ساده |
| Department/Unit | واحد سازمانی | بخشی از سازمان | بدون department_id |
| Person/Owner | شخص / مسئول | فرد پاسخ‌گو برای کار | شناسه شخص پنهان |
| Risk | ریسک | چیزی که ممکن است نتیجه را تهدید کند | risk ID پیشرفته |
| Dependency | وابستگی | کاری که انجام این کار به آن وابسته است | رابطه فنی پیشرفته |
| Monthly Review | بازبینی دوره‌ای | بررسی منظم وضعیت و تصمیم بعدی | نام فنی فقط در admin |
| Materialization | آماده‌سازی داده برنامه | تبدیل داده بررسی‌شده به داده قابل استفاده | فقط import/admin |
| Provenance | منبع و سابقه داده | فایل، برگه، ردیف و سلول منبع | ممیزی/پیشرفته |
| PULSE identifier | شناسه سامانه | شناسه‌ای که سیستم خودکار می‌سازد | read-only پیشرفته |

## الگوی پیام خطا

هر پیام سه بخش دارد: «چه شد؟ چرا؟ حالا چه کنم؟» نمونه: «این اقدام ذخیره نشد چون مهلت آن قبل از شروع فعالیت است. تاریخ را اصلاح کنید و دوباره ذخیره کنید.» متن‌هایی مانند foreign key violation، invalid parent_id و entity not found هرگز پیام اصلی نیستند.
