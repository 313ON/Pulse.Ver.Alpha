# راهبرد داشبوردهای PULSE

داشبوردها بر اساس intent ساخته می‌شوند، نه یک صفحه عظیم برای همه نقش‌ها. هر داشبورد باید یک خلاصه، فهرست نیازمند اقدام و مسیر drill-down داشته باشد.

| نقش | حداقل اطلاعات مفید | اقدام بعدی |
|---|---|---|
| مدیر ارشد | سلامت چرخه، پیشرفت راهبردی، KPIهای کلان، ریسک‌های مهم، نواحی تأخیردار | بازکردن واحد/هدف مسئله‌دار |
| مدیر واحد | عملکرد واحد، هدف‌ها و فعالیت‌ها، اقدام‌های عقب‌افتاده، بار تیم، ریسک و وابستگی | تخصیص/پیگیری و ثبت تصمیم |
| کارشناس | اقدام‌های assigned، مهلت، اولویت، progress، dependency و blocker | ثبت پیشرفت یا رفع مانع |
| کارمند | کارهای من، مهلت نزدیک، وضعیت ساده، اعلان و راهنمای قدم بعدی | انجام/به‌روزرسانی یک کار |
| مدیر سامانه | سلامت سامانه، کاربران، واحدها، تنظیمات، import و audit | رسیدگی به هشدار عملیاتی |
| ممیز | وضعیت governance، snapshot، provenance، audit و خروجی دقیق | مشاهده شاهد و export |

کارت‌ها نباید جایگزین فهرست قابل جستجو شوند. KPI بدون دوره، واحد، مقدار هدف/واقعی و توضیح معنا نمایش داده نشود. داده ناقص با برچسب «نیازمند تکمیل» از داده صفر یا موفقیت تفکیک شود.
